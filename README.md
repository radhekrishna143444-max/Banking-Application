# Banking Application

A simple Banking Application developed using Java and Object-Oriented Programming concepts.

## Features
- Create Bank Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- User-Friendly Console Menu

## Technologies Used
- Java
- OOP Concepts
- Eclipse IDE

## Concepts Practiced
- Classes and Objects
- Encapsulation
- Methods
- Conditional Statements
- Loops
